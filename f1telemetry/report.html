Full prediction, model test and data download

Race pace is a driver’s median comparable lap, as % slower than the fastest driver in that race. The prediction is a simple statistical model: the average of each driver’s last 5 races. It knows nothing about tracks, weather, upgrades, grid position or strategy, so it is the same for every remaining race, and it predicts pace, not finishing order.

How it works

  1. OpenF1 APItelemetry, laps, results
  2. Loadcached, retried
  3. Validate5 checks per sample
  4. StoreSQLite
  5. Analysecompare, predict, cross-check
  6. Reportthis page

Plain Python (pandas, numpy, SQLite, Plotly), with offline tests that run on every push. Code, data schema and design decisions are on GitHub.
